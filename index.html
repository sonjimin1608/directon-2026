무엇을 만들고, 무엇을 제출하고, 무엇으로 평가받는지 정리했습니다.

고객의 음성 문의를 실시간으로 듣고, 기업의 응대 매뉴얼에 맞춰 정확하게 응답하며, 필요한 업무는 함수 호출로 처리하는 음성 AI 상담원 서버를 구현합니다.

만들 것

  • WebSocket 기반 실시간 음성 AI 상담원
  • 고객 음성 입력 → 음성 응답
  • STT, LLM, Function Calling, TTS를 연결한 서버

제출할 것

  • 실행 가능한 프로토타입
  • 서버 소스 코드
  • 시스템 평가 결과 (실제 수치)
  • 최종 기획서
  • 최종 발표자료

평가받는 것

  • 사용자 경험 50점
  • 응답 품질 및 기능 구현 20점
  • 발표 및 질의응답 20점
  • 최종 기획서 10점

이 과제의 핵심은 속도 × 정확성 × 자연스러운 고객 경험의 균형입니다. 시스템 점수만 높여서는 좋은 평가를 받기 어렵습니다. 실제 고객이 쓰고 싶은 상담원을 어떻게 설계했는지가 평가의 중심입니다.

문제 상황과 목표

문제 상황

고객은 전화를 걸듯 말로 문의합니다. 상담원은 고객의 말을 듣고, 응대 매뉴얼에 맞게 사실대로 답하고, 업무 처리가 필요하면 시스템 기능(함수)을 호출해 처리해야 합니다.

여기에는 상충하는 요구가 있습니다. 답이 빠를수록 좋지만 틀리면 안 됩니다. 정확해도 말이 길고 어색하면 고객이 이탈할 수 있습니다. 음성 대화에서는 고객이 중간에 끼어들거나 말을 정정하기도 합니다.

목표

  • 고객의 요구를 정확히 파악해 업무가 자연스럽게 끝나는 상담을 제공합니다.
  • 실제 대화에서 어색하지 않은 응답 속도를 확보합니다.
  • AI가 처리할 범위와 사람 상담원에게 연결할 기준(Human Handoff)을 직접 설계합니다.
  • 설계 결정의 이유를 수치와 근거로 설명합니다.
